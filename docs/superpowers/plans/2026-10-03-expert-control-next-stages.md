# FR→RR 专家控制后续完整方案

**Goal:** 在固定质量、载荷与当前 I_I 仿真车型上，完成可复现、持续反馈、稳定直行且周期更短的 FR→RR 抬轮过坑专家策略。

**Architecture:** 保留 TruckSim nonlinear plant、当前输入接口及状态机。上层分配轮载和支撑稳定目标，下层分配主动悬架力；速度 PI、航向/横向反馈负责运动。先完成经典约束反馈，MPC 仅作为确有预测需求时的备选。

**Tech Stack:** TruckSim 2019、Python、NumPy/SciPy、pytest、Git/GitHub。求解步长 0.5 ms、控制周期 20 ms；不以 sleep 控制仿真时间。

**Spec:** [已审核方案](../../FR_LIFT_CRAWL_DEVELOPMENT_PLAN_20260929.md)、[偏航与时间证据](../../TIMING_AND_YAW_20261001.md)。本计划细化已有方案，不改变研究对象或质量/载荷。

## 技术选择与需要用户决策的边界

当前继续经典前馈 + 反馈 + 接触状态机 + 约束优化，不因“先进”而切换完整 MPC/WBC。只有出现明确的预测问题（例如停车与稳定约束无法由当前闭环协调）时，先量化原因，再提出小规模 MPC 的收益、算力和模型代价。

当前无需新增用户决定。以下改变另行用通俗语言提交选择：恢复原始悬架运动学、改变车辆/载荷研究对象、扩大到左侧轮或任意轮通用策略、降低既定验收/5 s 保持要求、因停车空间限制而改变场景或速度目标。正常测试、辨识、调参和版本更新继续自主执行。
