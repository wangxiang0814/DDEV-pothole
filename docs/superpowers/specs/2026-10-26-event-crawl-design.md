# 专家二分阶段自适应蠕行设计

用户已确认并授权直接开发：不追求坑内恒速或通行效率，前/后轮入坑、爬沿前主动降速，优先平顺、接触、姿态与可靠驶出；经典预瞄前馈＋反馈。阶段识别明确为逐轮状态机，非神经网络。常规实现和调参自行决策，不重复索取方案批准。

## 目标与边界

- 从坑前静止、调平、起步，前后轮完整通过并停车；单侧FR→RR，宽坑FL/FR→RL/RR。
- 整车低速通过区＋关键坑沿降速；实际速度/超速、停滞、倒溜独立记录，不用低均速掩盖波动。不优化通过时间，但拒绝永久停在坑前或坑中。
- 基线仍为用户采纳的MF52/3114，原车型和专家一不变。不改变坑沿5cm或硬件参数获得通过。软件能力±500Nm/1000Nm/s、±18200N/45400N/s；工作力6000N初始，真实行程/功率未标定。
- 原生仿真完整时长，不因姿态或失败截断，不导出视频。底盘真实接触未知仍标未评估。
- 历史恒速算法/验收/结果保持可追溯；新任务使用显式event_crawl配置和独立验收版本。新通过不得覆盖旧结果或暗中放松旧阈值。

## 选定结构

新增独立EventCrawlStrategy，复用同策略中性几何、模态分配和有界执行层；保留旧ShallowPressStrategy作匹配对照。worker显式按配置选择，新增依赖均冻结快照。无跨专家导入，共享合同不变。

1. WheelPhaseTracker：四轮独立的BYPASS/APPROACH/PREPARE/ENTRY/BOTTOM/CLIMB/RECOVERED，叠加UNLOADED/RECONTACT；几何＋Fz/CmpT迟滞，恢复驻留，状态实例内。倒退不伪造前后轴通过。
2. EventSpeedPlanner：按各轮到入/出坑沿的距离构造制动可达速度包络，坑区保持低速，关键沿更慢；限加速度/jerk。整车后轮清坑后才恢复/停车。最低爬沿推进由牵引环负责，不强求瞬间非零速度。
3. 阶段悬架：独立预瞄整形与接触目标；下降补支撑、触地减力、爬沿适度回缩；模态车身反馈和轮载反馈共同限幅。首先以旧力律＋新速度作为对照，逐项引入协调，禁止叠加多个未知增益。
4. 阶段驱动：速度PI、可实现驱动力分配、预瞄爬沿准备、失载轮速同步及重接地恢复；以实际可实现需求反馈积分器。正负转矩均遵守原速率。任何特殊模式不把离地轮扭矩当作有效牵引。
5. 新验收event_crawl_v1：保留姿态/行程/轮载/接触/轮速/方向/倒溜/输入/完整通过与停车旧门槛；用事件速度包络、规划跟踪、有限进展替换旧恒定均速条件，旧判据另列。追加分阶段舒适性与实际速度指标，不将RMS降低单独视为通过。

## 效率与实验

每个原生run独立进程，最多2并发；同一冻结计划执行期间不改源码。先2类10cm低速锚点，匹配速度规划的无主动悬架/旧力律/阶段力律对照；依据事件数据做单因素决策。失败3次即回到时序/可实现性归因，不继续盲扫。深坑通过后再扩大8/10cm、接近速度1–3，再覆盖1–6km/h接近速度、中间值与延时/误差。初始化距离包含加速和减速距离。

接触模型核验并行于控制工作，不等待MF-Swift授权；任何替代模型只做独立诊断，采用需另行决策。不得假称当前MF52数值结果已收敛或能证明实车安全。
