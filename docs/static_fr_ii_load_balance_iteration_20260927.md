# I_I 原地 FR 抬轮后三轮载荷优化（2026-09-27）

## 范围和结论

使用同一 1360 kg I_I、同一平坦物理路面、同一 200 kg 载荷后移 350 mm / 左移 500 mm 的隔离模型。先重放已成功的近零 FR 预载轨迹，再比较抬轮保持阶段的四角悬架力。未使用电机扭矩，未更换 TruckSim plant。结果是**原生仿真中的开环力轨迹加在线保护验证**，还不是可抗外扰的闭环蠕行控制器。

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 原成功轨迹 | 6490 N | 0 | 908 N | 5939 N | 0.0757 | 0.0681 | 16.2 mm | +0.02° / −2.83° |
| RL 额外 −2000 N，FL +100 N，FR lift −100 N | 6447 N | 0 | 1029 N | 5860 N | 0.0856 | 0.0771 | 12.6 mm | −0.57° / −3.45° |
| RL 额外 −3000 N，FL +100 N，FR lift −150 N | 6417 N | 0 | 1126 N | 5791 N | 0.0937 | 0.0845 | 30.4 mm | −1.13° / −3.88° |
| RL 额外 −4500 N，FL +0 N，FR lift −100 N | 6396 N | 0 | 1229 N | 5710 N | 0.1028 | 0.0922 | 41.7 mm | −1.85° / −4.24° |

最后一组将弱支撑轮载提高约 35%，三角形内的 ZMP 裕度提高约 35%。FR 在 10 mm 以上保持 5.66 s，无触发恢复，随后平滑落轮并回到四轮正轮载。保持段 FL 回弹行程约 88.7 mm，RL 压缩约 77.9 mm；施加悬架力 FL +7.68、FR −2.70、RL −7.86、RR +4.58 kN。这里的“正/负”严格指 `IMP_FS`/`FsExt` 原生通道符号；不能直接把符号当作车身“上升/下降”。软件力限为约 ±18.2 kN，未碰到该限幅。FR 离地高度较高，但本轮优化指标是三轮轮载和稳定裕度，不以抬高 FR 为优化目标。

## 为什么不能只把 RL 向下调

已抬轮工作点做了一次原生、同一运行中的 7 个 ±250 N 方向脉冲，全部完成且未触发保护。RL 通道 +250 N 使 RL Fz **减少 3.6 N**；RL −250 N 使其增加 **3.9 N**。FL +250 N 则使 RL 增加约 46 N，但 FL 回弹行程从约 78 mm 增至约 93 mm，接近 100 mm 几何限位。四角存在强耦合，单角“向下”与承载增加并非一一对应。在三轮静态支撑时，轮载由重心投影相对 FL–RL–RR 三角形的位置主导；现有总重心位于三角形内、靠近 FL–RR 边，RL 不可能仅靠改变该角作动力就与其余两轮平均分载。

因此，用户提出的“先 RL，再 FL/RR”适合作为**候选优先级**，不能写成无条件定时顺序。建议的反馈顺序为：

1. 四轮静稳后，先检查 CoM 和 ZMP 到三角边界的裕度、三支撑轮载、各角行程。若 RL 卸载方向经当前工作点辨识确实提高其轮载及裕度，再平滑施加 RL 预偏置；达不到改善则停在可行点并报告几何受限。
2. 再协同调 FL/RR 和 FR，按 **最小三轮轮载与最小稳定裕度优先** 的约束优化逐步降低 FR Fz；FR 近零且安全裕度持续满足后才能切到 SWING。不能仅依据预设时间或单个 Fz 瞬时值切换。
3. 抬轮后每个控制步测量四轮 Fz、CoM/ZMP、姿态、行程和 FR 净空，重新优化三支撑力与 FR 高度；同时限制 FL 回弹、pitch 和四角力变化率。若几何上达不到所需 RL 轮载，需调整载荷布局或下调左后轮驱动扭矩，不能以牺牲裕度来强求均载。

该顺序尚未形成完整实时闭环 FSM，本次通过的是有限条件下的静态保持与恢复。**三轮均载不是控制目标**；蠕行前需按各轮实际法向载荷与可用摩擦力分配扭矩，并验证抗扰、横摆和轨迹误差。

另做了“RL 优先”诊断：在 44 s（FR 已近零且裕度达标）提前施加 RL −4500 N，**45.1605 s FR 就已实际离地**，早于脚本计划的 48 s 抬轮阶段。轮载和裕度均保持安全，后续落轮也正常，但按当前预设模式时序判为 `EARLY_LIFTOFF`，不能当作合格的 FSM 全流程。其价值在于证实 RL 动作本身可能触发接触切换；正式控制必须在 lift-ready 持续成立后，依据实际 FR 接触/净空立刻切到 SWING，而不是继续等固定时间或仍按 STANCE 分配 FR 轮载。
