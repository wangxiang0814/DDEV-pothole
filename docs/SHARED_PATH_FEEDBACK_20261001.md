# FR/RR 共用路径与转向反馈验证

## 结论

`balanced` + RR `robust` + `--front-steering-feedback` 在三个代表工况下完成原生 FR→RR 全循环 PASS。质量、载荷、车型运动学副本、积分步长及原验收阈值均未改变。两阶段以 FR 初始化时的同一横向位置和方向为基准，解决了交接时重新定位目标而漏算累积误差的问题。

| 工况 | 结果 | 共用路径最大偏差 | RR 最低坑上净空 | RR 最弱支撑 | RR 最小轮载三角形坐标 |
|---|---|---:|---:|---:|---:|
| μ=0.7，标称起点 | PASS | 4.32 cm | 28.46 mm | 826 N | 0.0620 |
| μ=0.7，起点后移 0.3 m | PASS | 4.51 cm | 26.90 mm | 823 N | 0.0617 |
| μ=0.6，起点提前 0.3 m | PASS | 4.27 cm | 29.04 mm | 854 N | 0.0641 |

FR 蠕行最大偏差约 1.96–1.98 cm，两轮坑内实测速度均超过 3 km/h。FR/RR 各保持至少 5 s，停稳后再落轮并恢复四轮，无持续反馈饱和。标称完整动作约 101.8 s，远起点约 102.1 s；完成后观察 2 s 再结束求解。RR 横滚峰值约 9.00–9.35°，仍接近 10° 边界；三个单次 PASS 不等于随机扰动可靠性证明。

最终单元/接口验证为 274 passed。FR 路径指标由同一原生控制日志按共用原点重新评估，完整状态保持 PASS，原生轨迹没有修改。

数据与完整配置：`evidence/static_fr_ii/shared_path_matrix_20261001.json`。本机原生回放：`runs/shared_path_front_steering_{nominal,far,mu06_close}/model/output/`。只打开 VS Visualizer，不导出视频。

## 本次修复

1. 交接时将 FR 初始化路径坐标与方向传给 RR，RR 初始化不再重置。方向反馈和验收使用相同基准。
2. FR 蠕行/停车加入现有第九路 `IMP_STEER_SW` 的横向/横摆反馈，沿用已核实方向、50 Hz 更新、±220°方向盘限幅和 400°/s 变化率。转矩速度/方向反馈继续工作；初始化、卸载及静止抬轮不靠驱动制造惯性转移。
3. FR 异常恢复到 COMPLETE 后阻止启动 RR，避免失败后继续下一轮过坑。
4. 保留上一版 RR 停车行程反馈及姿态辅助，不增大执行器软件限幅，不降低轮载、三角形、净空、直行或保持门槛。
5. 精简矩阵生成器增加共用路径审计。旧结果原文保留，同时给出按统一基准复核的运动偏差，不覆盖历史结论。

## 对旧报告的修正

旧 RR 直行指标以 FR 恢复后的交接位置为零点。`feedback_stop_relief_mu07` 旧报告偏差 3.35 cm；统一路径复核约 6.75 cm。`feedback_stop_relief_mu06_close` 旧报告偏差 3.87 cm；统一路径约 6.80 cm。因此旧 PASS 仅对应当时分阶段路径验收，不能作为“整个流程相对原始路径 ≤5 cm”的证据。其抬轮、稳定支撑、过坑和恢复事实仍保留。

新标称试验实际修正共用路径偏差至 4.32 cm，新远起点修正至 4.51 cm。没有把路径零点移动到偏离后的位置以获得 PASS。

## 失败诊断及保留边界

| 诊断试验 | 观测 | 决策 |
|---|---|---|
| 轮速停车阻尼 | 远起点局部偏差仍约 6.32 cm，轮速峰值未明显下降 | 不默认启用 |
| 横摆反馈调整预载推进速度 | 支撑/净空改善，局部偏差仍约 6.29 cm | 不默认启用 |
| RL +3000 N 参与预载，FR 约 +6107 N | 横滚降至 7.44°，局部偏差约 6.07 cm | 不默认启用 |
| 静止预载方向反馈 | 局部偏差仍约 6.24 cm，净空降低 | 不默认启用 |
| FL 先调、FR 后调，静止转向，共用路径 | 偏差约 9.87 cm；越坑后姿态退出，平滑恢复四轮 | 不默认启用 |

上述功能通过显式实验开关复核，不是推荐配置。失败配置保存在矩阵内；成功版本未使用这些开关。代码审阅发现停车阻尼切换到蠕行/落轮的转矩跳变，已通过转矩状态交接与平滑释放修复，并加入针对性测试；该功能仍未证明能改善横移。

## 复核命令

```powershell
python scripts/run_right_side_full_cycle.py --output runs/shared_path_recheck --efficiency-profile balanced --rear-control-profile robust --front-steering-feedback --front-target-speed-kph 3.4 --front-min-pit-speed-kph 3 --front-brake-lead-m 0.5 --rear-target-speed-kph 3.35 --rear-min-pit-speed-kph 3
```
