# 浅坑物理预测器继续验证（2026-10-13）

**结论：可以取得车辆物理动力学模型，但本轮几个固定雅可比/接触近似预测器仍不能支撑完整过坑 MPC 的安全约束。未发布、未运行 MPC 闭环；专家二仍为 NOT_IMPLEMENTED。** 这不证明非线性混合 MPC 在原理上不可行。下一版主控制路线建议转向已知坑形预瞄前馈与反馈，MPC 保留为需要另行验证的研究分支。

## 验证的几个改进及边界

1. 固定67状态物理模型显式接收坑形高度和坡度；分别比较静止、匹配2 km/h工作点。
2. 加入单边轮胎力近似：禁止拉地，并把缺失的负轮载同时反馈到状态加速度和直接输出加速度；不是只把图上的负数截掉。
3. 每个预测起点使用当前原生状态的因果0.5 ms后向导数和当前输出建立仿射偏置；离地时用当前负轮胎压缩量表示间隙，避免把真实自由落体的修正重复加一次。整个未来窗不再重置实测输出。
4. 提取14个垂向原生状态（车身升沉/侧倾/俯仰及其速率、四角行程及其速率），排除冻结平地模型中不适合搬用的转向、制动和轮胎滑移隐状态。它不能预测完整纵横向动力学，车速误差门槛仍照原要求保留，不能据此声称转矩/转向 MPC 已构建。
5. 把空间地图预瞄和模型传播细化到1/0.5 ms，控制命令仍保持20 ms周期，不改变 TruckSim 的0.5 ms积分步长。两者0.2 s最差角轮载RMSE变化最大约3.1 N，失载误判依然存在；这是预测器步长检查，不是原生求解器收敛证明。

所有试验使用原生真值初始化，并使用事后已知的实际未来命令，属于对模型有利的植物预测测试，**尚未解决真实传感器估计、控制优化器、时延或真实执行器动态**。正式预瞄仅用当前接触点位置、当前车速和航向在配置地图上推进，没有未来真实轮位。接触点迁移、轮胎包络、接触面法向的大幅变化、非线性弹簧/止挡和摩擦耦合仍未完整建模；误差原因尚不能逐项定量归因。

部分冻结67状态候选在宽坑6 cm给出非常大的预测轮载，这是预测器在工作域外的失真，不能拿来当作 TruckSim 的实际轮载或车辆失稳数据。

## 技术路线决定

当前应停止把这几个预测器当作全车悬架/转矩/转向安全 MPC 的候选直接放行。对轮载的假支持会使优化器错误分配驱动转矩，尤其在两前轮/两后轮过宽坑和退出重接地时，预测约束可行不代表车辆实际可行。底盘真实几何依然未知，触底安全也不能由悬架行程替代。

**建议主策略改为预瞄前馈＋状态反馈，先1–3 km/h：**

- 空间预瞄按轮迹安排降速、进坑下压、坑底承载及退出恢复，过坑速度由坡度、行程余量和接触状态调节；前后轴都退出才结束任务。
- 悬架前馈根据坑形生成连续行程/支撑分配目标，叠加姿态、垂向速度、行程与轮载反馈；用限幅/限速与接地、离地、重接地状态机处理尖锐边缘。力方向先独立扰动验证，不能把下压理解成统一施加正力。
- 分布式驱动按实际轮载与保守附着预算分配总牵引，低速同时限制轮速差和滑移，失载轮卸转矩，重接地渐进恢复；不能靠持续增加总转矩解决爬坑失败。
- 转向维持横向位置、航向/横摆反馈；加入转矩左右差的横摆约束，分别验证单侧与宽坑。悬架、转矩、方向盘沿用专家一对齐的能力上限，状态和调参文件独立。

这些是下一开发阶段的设计安排，**尚无前馈反馈闭环改善证据**。如继续研究 MPC，需先建立具有轮胎几何接触守卫、非线性支撑/止挡、摩擦及工作点切换的混合模型，再做独立预测、状态估计和求解时间验证；本轮没有真正实现线性时变矩阵沿预测轨迹重线性化，也没有检验非线性MPC的最终上限。MPC 可后续用于已有合格局部模型的平滑路段姿态/速度规划，不宜把本轮失败推广为所有MPC都不可能。

入口：`run_shallow_physical_probe.py` 每次单独进程、认领运行目录；`analyze_shallow_physical_probe.py --anchored --vertical --road-step-s .0005 --output <新目录>` 重建最终分析，拒绝覆盖。工况名称与源历史见 [case_index.md](../evidence/shallow_physical_mpc_20261013/case_index.md)，无需保存视频，日后可直接原生回放。
